# hybrid-kem-mqtt-proverif
ProVerif models of the Hybrid KEM-MQTT handshake (Dong et al., TCHES 2026): symbolic analysis of secrecy, authentication and forward secrecy when ECDH, the KEM, or static keys are broken or leaked. Accompanies the paper "A Symbolic Analysis of the Hybrid KEM-MQTT Handshake under Component Compromise".
